## ⚠️ ФУНДАМЕНТАЛЬНЫЙ СТАТУС: 1-loop EFT

**Ω⁴-UNIFIED — это 1-loop EFT.**

Все структурные результаты получены в **1-loop приближении**.
Многие результаты — это **ПРОПОРЦИИ**, не теоремы.

### Аналогия

```
Пробег: 200 км
Бензин: 18 литров
Расход: 18×100/200 = 9 л/100 км  ← пропорция

УФ-точка: g* = 7.30
Экспонента: θ₁ = −3.30
Инвариант: g* + θ₁ = 4  ← пропорция
```

**Обе — структурные пропорции. Обе — эмпирические.**

## ЧАСТЬ 6: ВОЛНОВАЯ ФУНКЦИЯ МЕМБРАНЫ

### Общая идея

Мембрана Ω⁴ (4D-пространство-время) моделируется как **квантовомеханическая система**. Каждое из 4 измерений описывается 1D-потенциалом Пёшля-Теллера.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│  МЕМБРАНА Ω⁴ — 4D ПРОСТРАНСТВО-ВРЕМЯ                                   │
│                                                                         │
│  Ψ(x₁, x₂, x₃, x₄) = ψ₁(x₁)·ψ₂(x₂)·ψ₃(x₃)·ψ₄(x₄)                      │
│  E_total = E_{n1} + E_{n2} + E_{n3} + E_{n4}                           │
│                                                                         │
│  ФИЗИЧЕСКИЙ СМЫСЛ:                                                     │
│    E_total → СПЕКТР МАСС частиц на мембране                            │
│    Ψ(x₁,...,x₄) → ВОЛНОВАЯ ФУНКЦИЯ состояния                           │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 1D-модель Пёшля-Теллера

```
V₁(x) = a² − a(a+1)·sech²(x)

При a = 7:
V₀ = a(a+1) = 56
Спектр: E_n = 0, 13, 24, 33, 40, 45, 48, 49
ΔE = E₁ − E₀ = 2a − 1 = 13
```

### ★ Численное решение v2.1 (КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ)

**ПРОБЛЕМА (v2.0):**
```

Матрица H размера 8000×8000
Результат: E_num = [0, 0, 0, 0, 0, 0, 0, 0]
max_dev = 49.0 ❌
```

**РЕШЕНИЕ (v2.1):**
```python
from scipy.linalg import eigh_tridiagonal

diag = 2.0 / dx**2 + V(x)
off_diag = -1.0 / dx**2 * np.ones(N - 1)

E, psi = eigh_tridiagonal(
    diag, off_diag,
    select='i',
    select_range=(0, n_eig - 1),

```

**Что даёт:**
- Не строит полную матрицу `N×N`

### 3. 2-loop нарушение инварианта
